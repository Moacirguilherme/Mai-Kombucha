# 🧉 Mai Kombucha - Website institucional

Site desenvolvido para a marca **Mai Kombucha**, uma empresa artesanal focada em bebidas naturais e saudáveis, com identidade jovem e conteúdo informativo. Projeto feito como freelancer, 100% personalizado.

## 🔍 Visite o site

https://moacirguilherme.github.io/Mai-Kombucha/

---

## 🎯 Objetivo

Divulgar a marca Mai Kombucha de forma moderna, visual e atrativa. O site apresenta os sabores da bebida, explica seus benefícios, estimula parcerias e convida o público a conhecer o estilo de vida saudável com kombucha.

---

## 🧰 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome (ícones)
- Google Fonts (Montserrat)
- Responsividade em andamento

---

## ✨ Funcionalidades

- ✅ Carrossel de imagens com botões de navegação
- ✅ Seções animadas com efeito *slide-in*
- ✅ Animação de bolhas subindo (efeito visual de gás/refrigerante)
- ✅ Seções bem definidas: Sobre, Sabores, Benefícios, Parceiros
- ✅ Ícones de redes sociais e links diretos para WhatsApp
- ✅ Favicon e identidade visual da marca
- ✅ Estrutura pronta para adaptação mobile
